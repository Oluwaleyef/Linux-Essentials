**HACKMINDS LINUX CHALLENGE #002**

**OPERATION: THE MISSING FILES MYSTERY**

Challenge Category: Linux System Administration & File System
Investigation Difficulty Level: Intermediate --- Advanced Beginner
Duration: 45 Minutes Total Marks: 100 Pass Mark: 75/100

------------------------------------------------------------------------

**1.  CHALLENGE BRIEFING**

**Mission Background**

A Linux investigation workspace has been assigned to the HACKMINDS
investigation team. Several pieces of digital evidence must be
organized, verified, investigated, and secured.

Your task is to build the investigation workspace, create the required
evidence files, discover hidden evidence, manage temporary files, apply
file permissions, conduct a file system audit, and archive the evidence.

You are expected to demonstrate practical Linux knowledge, attention to
detail, file system management, and the ability to verify your own work.

**Mission Objectives**

By the end of this challenge, you should be able to:

- Create and manage nested directories.
- Create files and maintain their required contents.
- Identify and investigate hidden files.
- Perform temporary file creation, renaming, verification, and removal.
- Apply and inspect Linux file permissions.
- Search for files and text within a directory structure.
- Count regular files.
- Create and inspect compressed archives.
- Generate and verify checksums.
