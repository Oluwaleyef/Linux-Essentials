**OFFICIAL CHATGPT EXAMINER PROMPT**

Challenge: The Hidden File Mystery Time limit: 30 minutes Total marks:
100 Pass mark: 75

**CHALLENGE TASKS**

The participant was instructed to:

**LEVEL 1 --- DIRECTORY AND FILE CREATION**

- Create a directory named "HACKMINDS".
- Enter the directory.
- Create a file named "mission.txt".
- The file must contain:

"HACKMINDS members learn Linux through practice."

**LEVEL 2 --- HIDDEN FILE INVESTIGATION**

- Create another text file containing:

"The real learning begins when you explore."

- Make the file hidden.
- Demonstrate the difference between a normal directory listing and a
  listing that includes hidden files.
- Display the hidden file's contents.

**LEVEL 3 --- FILE PERMISSIONS**

- Inspect the permissions of "mission.txt".
- Set the permissions so that:
  - Owner: read and write.
  - Group: read only.
  - Others: no permissions.
- Verify the resulting permissions.

**LEVEL 4 --- FINAL INVESTIGATION**

- Display all files, including hidden files.
- Display the contents of the files.
- Identify which file is hidden.
- Count the regular files in the directory.

**KNOWLEDGE QUESTIONS**

Assess the participant's answers to these six questions:

1.  What makes a file hidden in Linux?
2.  Does hiding a file mean that it is encrypted or password-protected?
3.  What is the difference between a normal directory listing and one
    that includes hidden files?
4.  What does the permission string "-rw-r-----" mean?
5.  What is the numeric permission value of "-rw-r-----"?
6.  Why are file permissions important in Linux?
